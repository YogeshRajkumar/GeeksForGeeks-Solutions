<h2><a href="https://www.geeksforgeeks.org/problems/longest-k-unique-characters-substring0853/1">Longest Substring with K Uniques</a></h2>

<h3>Difficulty Level : Difficulty: Medium</h3>

<hr>

<div class="problems_problem_content__Xm_eO">

<p>
Given a string <strong>s</strong> and an integer <strong>k</strong>, your task is to find the length of the longest substring that contains exactly <strong>k</strong> unique characters. If there is no such substring, return <strong>-1</strong>.
</p>

<p><strong>Examples:</strong></p>

<pre><strong>Input:</strong> s = "aabacbebebe", k = 3
<strong>Output:</strong> 7
<strong>Explanation:</strong> The longest substring with exactly 3 unique characters is "cbebebe", which has a length of 7.</pre>

<pre><strong>Input:</strong> s = "aaaa", k = 2
<strong>Output:</strong> -1
<strong>Explanation:</strong> The string contains only 1 unique character, so there is no substring with exactly 2 unique characters.</pre>

<pre><strong>Input:</strong> s = "aabbcc", k = 1
<strong>Output:</strong> 2
<strong>Explanation:</strong> The longest substrings with exactly 1 unique character are "aa", "bb", or "cc", each having length 2.</pre>

<p><strong>Constraints:</strong><br>
1 ≤ s.size() ≤ 10<sup>5</sup><br>
1 ≤ k ≤ 26
</p>
